# كسلان — موقع تسويقي

صفحة تسويقية ثابتة (HTML/CSS بدون بناء) لأداة **كسلان** — إضافة كروم لتنزيل
وتحليل فواتير وإيصالات منظومة الفاتورة الإلكترونية المصرية.

## الملفات

- `index.html` — الصفحة الرئيسية (المزايا، معاينات لوحة التحكم، الأسئلة الشائعة).
- `privacy.html` — سياسة الخصوصية (نفس النسخة المطلوبة لقوائم Chrome Web Store).
- `icons/` — أيقونات الإضافة، مستخدمة كـ favicon.

## النشر عبر GitHub Pages

1. ادفع هذا المجلد كمستودع على GitHub.
2. من إعدادات المستودع (Settings → Pages)، فعّل GitHub Pages على فرع `main`
   والمجلد الجذر (`/`).
3. الموقع هيبقى متاح على `https://<username>.github.io/<repo>/`.

لا يوجد أي خطوة بناء (build step) — الملفات جاهزة للنشر مباشرة.
